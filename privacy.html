OWA CALENDAR BRIDGE

Данные и разрешения

Обновлено 22 октября 2026 года. Независимый открытый инструмент для ручного переноса встреч из OWA в Google Календарь.

Какие данные используются

Userscript читает названия, время, описания, место и ссылки на звонки в вашей авторизованной вкладке OWA. При нажатии «Синхронизировать» эти данные передаются напрямую в Google Calendar API и сохраняются в отдельном календаре вашего аккаунта. Участники и приглашения не переносятся.

Вход через Google запрашивает адрес аккаунта, его идентификатор и разрешение calendar.app.created: создавать дополнительные календари и работать с событиями календарей, созданных приложением. Адрес нужен для отображения выбранного аккаунта, идентификатор — для выбора его календаря. Приложение не запрашивает чтение всех ваших личных календарей.

Где хранятся данные

Краткоживущий access token, выбранный аккаунт и идентификатор календаря хранятся локально в хранилище Tampermonkey. Там же сохраняются подготовленные данные встреч за последний прочитанный период — названия, время, описания, место и ссылки — для пропуска неизменённых событий. Локальный кеш можно сбросить через меню «Полная проверка при следующей синхронизации». Токен передаётся между вкладками через хранилище userscript, не через URL. Для автоматического продления доступа refresh token хранится зашифрованным на сервере службы подключения eovdienko.ru. Случайный ключ подключения устройства хранится в Tampermonkey. Сервер получает код авторизации, адрес и идентификатор Google аккаунта; содержимое встреч через него не передаётся. Пароль Google приложение не получает. Cookie, сертификаты и canary OWA используются только на рабочем сервере и в Google не передаются.

Сайт не хранит базу встреч, не получает их на сервер и не использует аналитику. Страницы размещены на GitHub Pages: GitHub обрабатывает обычные запросы к сайту согласно своей политике конфиденциальности. Библиотека входа и API предоставляются Google.

Как отключить и удалить

Кнопка «Отключить на этом устройстве» удаляет серверное подключение и локальный вход. При недоступности сервера повторите отключение после восстановления связи. Перед удалением userscript сначала отключите Google этой кнопкой или отзовите разрешение. Разрешение Google можно отозвать в подключениях Google аккаунта. Для удаления сохранённых встреч удалите календарь «Работа · OWA» в Google Календаре. Удаление userscript не удаляет копии в Google.

Использование данных Google ограничено описанной синхронизацией в соответствии с Google API Services User Data Policy, включая Limited Use. Данные не продаются, не передаются рекламодателям и не используются для обучения моделей.

Переносите рабочие данные только при разрешении организации. По вопросам работы и обработки данных: Issues проекта. Не прикладывайте токены и реальные данные встреч к публичным обращениям.
