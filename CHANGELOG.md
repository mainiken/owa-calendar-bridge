# Изменения

## 1.5.1 — 2026-10-22

- Поддерживается стандартное OpenID-разрешение `email` в ответах Google наряду с `userinfo.email`.
- Неподтверждённые разрешения выявляются на странице входа до отправки кода серверу.
- Ошибки первичного подключения больше не выдаются за временный сбой продления доступа.
- В серверную диагностику включены только код ошибки и признаки разрешений; токены, коды входа и данные аккаунта не записываются.

## 1.5.0 — 2026-10-22

- Добавлена серверная авторизация с refresh token: при истечении доступа синхронизация продлевает его без повторного входа.
- Существующий календарь сохраняется; для перехода после обновления нужен один повторный вход.
- Ключи Google хранятся зашифрованными на сервере, встречи продолжают передаваться напрямую из браузера в Google.
- Сетевой сбой не сбрасывает подключение; HTTP 401 вызывает однократное продление и повтор запроса.
- Добавлены проверки перезапуска, продления, отзыва, временных ошибок и отключения устройства.

## 1.4.0 — 2026-10-15

- Неизменённые встречи с той же версией Exchange читаются из локального кеша: повторные GetItem для описаний не выполняются. Без ChangeKey сохраняется полная проверка описания.
- В OAuth счётчик отправки показывает только реальные записи; для сверки Google запрашиваются служебные метки без описаний.
- Apps Script пропускает повторную передачу подтверждённых описаний в течение суток и продолжает проверять отмены по полному списку ключей.
- Добавлена команда полной проверки без удаления входа или календаря.
- После подтверждения аккаунта показан экран успеха с адресом Google; настройки сохраняются, вкладка закрывается автоматически. До подтверждения ошибка не подменяется успехом.
- Добавлены проверки 170 встреч: повторный запуск без GetItem и записей Google, одно изменённое описание, отмена, повтор после ошибки и подтверждение перед закрытием вкладки.

## 1.3.2 — 2026-10-15

- URL страницы входа содержит версию релиза, чтобы повторный вход не использовал сохранённый HTML предыдущей версии.
- Сборка автоматически добавляет хеш содержимого к адресам JavaScript и CSS страницы подключения. Изменение файла меняет его адрес в браузерном кеше.
- Версия страницы видна в заголовке; после авторизации сохраняется версия в адресе страницы.
- Ссылка перехода со стартовой страницы ведёт на установщик с версией. CI проверяет воспроизводимость всех генерируемых страниц.

## 1.3.1 — 2026-10-15

- Связь страницы Google с userscript переведена на строковые DOM-события: больше нет зависимости от MessageEvent.source и общей JavaScript-среды.
- Userscript явно использует изолированный DOM-контекст Tampermonkey, совместимый со строгой CSP страницы подключения.
- Правило запуска страницы подключения допускает query string; обработчик по-прежнему проверяет точный origin и путь.
- Добавлены отдельная диагностика истёкшего запроса и продолжение проверки при позднем запуске userscript.
- Добавлен тест полного обмена между двумя изолированными JavaScript-контекстами с общим DOM. Реальная проверка на пользовательском устройстве остаётся необходимой.

## 1.3.0 — 2026-10-15

- Добавлен вход через Google Identity Services и прямая синхронизация с Calendar API без личного Apps Script.
- Используется разрешение calendar.app.created для отдельного календаря «Работа · OWA»; адрес аккаунта показывается в настройках.
- Передача доступа между вкладками идёт через хранилище Tampermonkey с одноразовым nonce. Токены не включаются в URL; Client secret не используется.
- Добавлены восстановление копий по стабильным ID, проверка принадлежности, повторный вход и локальное отключение.
- Существующие подключения Apps Script сохраняются. OAuth создаёт отдельный календарь, старые копии остаются в прежнем.
- Обновлены инструкции для MacBook, тестового доступа OAuth и описания обработки данных.
- Автоматические проверки используют имитацию Google. Реальный вход и синхронизация на MacBook ожидают пользовательского теста.

## 1.2.1 — 2026-10-15

- Страница установки опубликована на GitHub Pages: скачивание архива больше не требуется.
- В README добавлены получение всего проекта через Git/GitHub CLI и установка userscript по прямой ссылке.
- Добавлена инструкция владельцу приложения по созданию OAuth Client ID для будущего входа через Google. Сам OAuth-вариант ещё не реализован.

## 1.2.0 — 2026-10-15

- Добавлена подробная инструкция с установкой Tampermonkey, разрешениями Chrome/Edge, настройкой Google и первой синхронизацией.
- В странице установки появился выбор адреса OWA и подготовка userscript, ограниченного этим сервером.
- Описаны получение ключа, выбор функции в Apps Script и настройка доступа Google без входа.
- Подготовлены публичный репозиторий GitHub и архив установки для коллег.
