# Изменения

## 1.1.0

- Подготовлен самостоятельный репозиторий и пакет для коллег без личного адреса развертывания и корпоративного домена.
- Источник определяется по текущей HTTPS-вкладке OWA; обработчик закрепляет профиль за первым сервером.
- Добавлены документация установки, описание передаваемых данных, лицензия MIT и проверка файлов перед передачей.
- Добавлена смена ключа через `rotateConnectionKey` без удаления календаря.
- Сохранены исправления вывода ключа при настройке и диагностики страницы входа Google.
- Добавлены воспроизводимые npm-команды, lockfile и CI с искусственными данными.
